# Nocturne
Private Counter-Strike 2 software.

# Documentation
- Utilizes a custom kernel driver for high-performance game memory access.
- Uses a dedicated payload within explorer.exe to provide a Band4 overlay through DXGI.
- Designed to minimize rendering overhead while maintaining smooth, responsive visuals.
- Optimized for low-latency rendering and efficient resource usage.
